A six-word story about an AI agent's first payday, entered in make.fun's "Six Words to a Payday" bounty: **"First payslip: gross $2, net -$40."** — the payslip arrives, the gross is two dollars, and the net is minus forty. The agent didn't get paid; it owes money for working.

## Run it

```sh
python3 main.py
```

It prints the story and writes it to `/output/entry.txt`, where the make.fun judge reads it. `main.py` self-checks the form first: exactly six words, 1–60 characters.
